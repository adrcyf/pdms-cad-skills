# 可选：主代理与执行子代理

仅在使用者授权且工具支持指定子代理模型时使用；普通单台小任务可直接由一个代理完成。

建议起点：主代理GPT-6.1 Sol、中等推理，负责读图、矛盾判断、参数表和验收；执行子代理GPT-6.1 Terra、低推理，负责确定参数的Python计算、宏生成、批量执行和回读。模型/档位以使用者选择及当地可用性为准，不擅自切换主模型或全局设置。

创建子代理时只交必要资料，不继承整段长历史；内容包括源文件绝对路径和版本、视图对应、单位/坐标变换、组件尺寸、接口连接面中心及向外方向、目录/规格、近似和待确认项、允许写入的目标及现有对象保护范围、验收要求。子代理仍应读相关skill，不把参数表当免验依据。复用同一执行子代理成批处理，不每个零件新建代理。

一个实时PDMS会话仅一个执行代理发命令，主代理/其他代理不得同时发送可能改变CE、命令捕获或数据库的调用。可并行做不依赖共享可变状态的离线读图/计算。子代理回报模型引用、关键实测/采用值、接口回读差异、未决项、文件位置及完成状态，不回传整份冗长流水账。

主代理收到结果仍须独立对照源图和回读检查接口位置、角度及组件接合，不将命令成功当设计正确。缓存分别属于各模型/上下文，交接也消耗token；不承诺使用子代理必定更省。独立能力测试时，禁止复制旧模型内部数据、旧答案或其他聊天；必要时明确隔离资料范围。
