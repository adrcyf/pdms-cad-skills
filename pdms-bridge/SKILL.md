# PDMS 本地命令桥接

原作者及维护者：adrcyf。允许分享、修改；保留来源说明，另记修改者。项目报告填写实际编制人。

默认按软件会话维持MCP连接、CAD读取通道与图纸缓存，连续命令复用同一工作进程，不逐条启动/退出。优先使用pdms_status/pdms_execute/pdms_result/pdms_record；先status，再绑定session。Design关闭或已连接的原生会话登出后，MCP及自有读取子进程统一退出，不结束用户CAD/PDMS。仅CAD工作时绑定CAD进程，开始Design会话后优先绑定Design。Python CLI作为后备，不把它的逐次启动模式当默认。此规则覆盖此前误改的“按每条指令启停”。

当前状态：2026-10-27 已在 PDMS 12.1 SP4 当前会话跑通 Python/MCP 实时查询、NOZZLE 世界 P1、变量赋值、独立临时 EQUI 创建/移动/清理、命令错误捕获及已证明归属本桥接的遗留日志自动恢复。复测没有使用窗口控制。具体证据与尚未覆盖的范围见连接参考。

## CAD 直接读取

优先用cad_active_read读取用户已打开的AutoCAD，核对完整路径，再按Handle/类型读取几何、Measurement与TextOverride，不向控制台模拟输入。同一软件会话复用CAD工作进程、原生COM辅助通道和文件解析缓存；文件变更仍核对mtime/尺寸，实时COM读取最新值。cad_summary/cad_query/cad_preview为保存文件备用通道，不包含未保存修改；CLI为后备。图像只辅助理解，尺寸取图元；只截图不代表允许激活窗口或点选。详见 [CAD读取与依据](references/cad-reading.md)。

## 分享与一次性准备

整个skill包含兼容PDMS12.1 SP4的DLL、源代码、加载宏生成器及Python/MCP脚本。默认pdms.cmd准备MCP会话，并备份、注册本桥接的Design自动加载项；只需准备一次，DLL/计时器随Design生命周期运行。已打开但尚未加载的Design手动运行一次生成的宏，ready时不重复加载。不要每做完一条命令或一句对话就调用stop；stop只用于用户明确结束整个桥接会话。

pdms.cmd -InspectOnly -NoPause只检查；pdms.cmd -NoPause准备默认会话模式。-ManualOnly可另选手动加载，-NoMcp可另选CLI。先打开CAD/Design再开始建模任务；如果启动MCP后10秒内仍没有软件会话，它会退出。软件关闭后stdio服务结束，下次软件会话需客户端重新连接；不能承诺任意Codex版本都能无操作自动重连。CLI可后备处理，但不把它说成已恢复持久MCP。详见连接参考。

## 路径与一次性加载代码

不要照抄其他电脑的用户名或路径。根据本 SKILL.md 实际位置定位同目录 scripts/show-load-command.ps1，先部署适配 DLL，再运行该脚本；它按当前 USERPROFILE 和脚本所在目录生成 bootstrap.mac，并打印、保存本机实际加载代码到 scripts/load-command.txt。助手自行定位并给出生成后的完整一行，不要求使用者寻找文件，也不在已 ready 的会话反复加载。默认安装位置可执行：

```powershell
& "$env:USERPROFILE\.codex\skills\pdms-bridge\scripts\show-load-command.ps1"
```

生成加载代码不会自行安装 DLL、连接 PDMS 或登记 MCP。目标电脑安装目录不同时，将已核实的 PDMS 根目录传给 deploy.ps1 的 -PdmsRoot；不同版本需适配验证，不能承诺复制即可用。路径含空格或 CP936 无法编码字符时单独处理并验证，不猜宏文件名语法。

- 在已获用户授权的范围内批量发送完整命令单元；查询只取决策所需字段，避免反复 Q ATT。几何计算在本地 Python 完成，再发送确定值。
- 日志是桥接自然产生的收发/捕获文件，不额外转写命令流水账。重要工程结论写用户要求的核对表/报告；必要临时命令笔记在任务收尾清理，不默认用pdms_record永久复制回传。已有交付和历史证据不得误删。
- 命令窗口与磁盘日志分开：每批回传结果、关闭捕获文件后，自动ALPHA REQUESTS CLEAR及ALPHA COMMANDS CLEAR清屏，避免显示积累；错误分支同样清屏。这不重启连接，也不删除磁盘日志。
- 工作期间保留当前会话的日志、宏和请求记录，不逐批删除；只有用户明确要求清日志（pdms_clear_history或CLI clear --session ...）或软件会话退出时才整理。退出时清理已完成临时包、丢弃普通详细历史；保留最多100条精简摘要，重要记录/交付文件/未决请求/未知异常文件保留。关闭捕获文件不是删日志，不能混淆。按本机约定单独检查属性，再用PowerShell LiteralPath普通删除，不强制或递归清理。
- 宏默认$R0关闭逐行跟踪，ALPHA LOG使用本机已验证的OVER语法捕获原生输出，不使用不兼容的REQUESTS尾参；查询回传和每批清屏继续保留。2026-10-28重开后已验证查询、变量执行、错误停止及成功/错误清屏；不能声称已取消所有系统提示。
- 当前 CE、RefNo、世界坐标、单位和目录必须来自当前会话。使用建模/配管 skill 决定工程语义，本 skill 只负责执行和回传，不代替图纸与连接核实。
- 执行失败会停止后续行，但没有事务回滚，之前成功的写入可能已生效。超时不自动重发；用 request_id 查结果并核对数据库。跨调用优先使用绝对定位与固定引用，不依赖临时局部变量。
- status 必须 connected 且 ready，unresolved_requests 为空后才能发新单元。日志由客户端的原生错误处理宏管理，不嵌套 ALPHA LOG；Result 为空不等于没有输出，读取捕获日志及原生完成状态。没有完成状态不能报成功。
- 普通命令错误由原生 HANDLE ANY 捕获，返回原错误文本、停止后续行并关闭本批日志。捕获开始前遇 (61,275) 且路径、运行记录证明为当前 session 的桥接日志时，自动释放并重试一次；此时用户命令尚未执行。未知/其他人的日志不关闭，超时和已执行过的写入不重发。
- 自动恢复已覆盖上述两种测试场景，不等于能关闭任意弹窗或恢复崩溃。遵守用户“不操作窗口”的要求；Python 发送窗口消息、模拟点击/按键也不能冒称原生命令通道。已发生的模态阻塞没有独立恢复接口时如实报告，不能擅自终止进程或丢弃未保存模型。
- 命令执行成功不等于设计正确、保存成功或三视图验收通过。保留必要回读；外观验收仍需对应视图。
- 模块切换、重启、弹窗或长任务可能使心跳暂停。重新检查连接，不能因此复制运行 NEW。不要注入进程、模拟键盘或修改 Windows 安全配置来绕过加载。

适配范围：本机 PDMS 12.1 SP4、.NET 2.0 x86。使用本机标为 AVEVA USE ONLY 的 CommandLine.Command 封装，属于版本适配，不是厂商保证的公共接口。其他版本需重新编译和验证。真实连通与写入验证状态见 references/connection.md，不夸大已测试范围。

日志说明：日志指Python/MCP收发及原生命令捕获产生的过程文件，不另行转写命令流水账。必要的临时笔记在任务收尾按明确清单清理；仅用户要求的交付核对表/报告保留工程结论，不自动调用pdms_record永久复制原始命令回传。既有项目证据不在本次删除范围。

## 按需打开CAD（已获此授权的工作流）

本使用者允许需要时通过原生COM启动AutoCAD并打开指定资料，不抢占鼠标键盘。先检查会话/已打开文档；缺失时运行 scripts/ensure-cad-open.ps1 -Path <已核实绝对DWG或DXF路径>。新建应用保持隐藏；复用现有应用时不改Visible、不调用Activate/SetForegroundWindow，不发SendCommand或模拟输入。按只读方式打开，不保存、关闭用户文档或退出用户软件；软件忙碌/授权弹窗时返回问题，不用GUI接管。自动启动可能受本机首次初始化、许可证或版本限制，不保证所有电脑无提示。

随后cad_active_read传expected_path，按完整路径读取已打开Documents内目标（无需把它切成活动文档）。其他使用者如明确限制启动，应服从其限制。PDMS自动加载迁移需在目标电脑执行一次pdms.cmd准备，定位当地安装目录、部署兼容DLL并备份登记本桥接DesignAddins项；只有复制skill不会自动登记。打开中的Design需手动加载一次或正常重启；其他版本须重新核验。
