# PDMS 配管命令与易错点

## 使用与证据等级

适用于本次 Windows PDMS 12.1 SP4 会话经验，不保证其他版本或数据库相同。以下用 `REF_*`、`SPEC_*` 表示编写者要用当前已验证值替换的说明性位置；含这些标记的块不是用户可直接运行的脚本。真实交付必须填实，不得把本案例位号、RefNo、目录或坐标当默认。

- **会话回读验证**：查询、基本元件创建、CONNECT、DIR、POS、BY、LSTUBE、软管长度和视图命令曾有成功执行及输出。
- **仅语法来源**：REORDER 的 BEFORE/AFTER 用法在本机 `PMLLIB/design/forms/componentcreation.pmlfrm` 和 `cblCway.pmlfrm` 中存在；不等于本次用户已完整回读所有重排结果。
- **未完成验证**：从零创建 PIPE/BRAN 的整套纯命令模板未在本次会话独立跑通；不将其编造成已验证可执行模板。生成新管代码前查本机原生创建逻辑/手册，验证正确所有者、命名及规格初始化；具备安全隔离和授权时才做最小创建验证。

## 最小读数包

按决策取子集，不每次全文 Q ATT。Q MEM 返回当前成员及 RefNo；按名称导航后确认输出来自预期对象。

```text
/PIPE_NAME/BRANCH_NAME
Q HREF
Q TREF
Q HPOS
Q TPOS
Q HSTUBE
Q MEM
```

设备口/组件：

```text
/VERIFIED_OBJECT_PATH
Q POS WRT WORLD
Q ORI WRT WORLD
Q SPREF
Q P1
Q P2
```

只查询该对象支持的属性：NOZZLE 用 CATREF；没有第二口的对象不查 P2。BRAN 没有一般实体的 POS/ORI，使用 HPOS/TPOS/HDIR/TDIR。Q P1 输出的坐标基准要看实际上下文；不能因前一行 Q POS WRT WORLD 就认定后面的 P1 也是世界坐标。确认目录 P1 对原点的偏移并转换，必要时比较已知端点校验。

查地面：必须选择实际板件或落地支撑的几何基本体，再读 Q ATT、世界位置和朝向，依形体尺寸算上/下表面。查到 BRAN 的属性不构成地面证据。阀门管中心高度减站立面只给中心离地高度，还需手柄/手轮包络和可达性。

## 新管命令编写清单

此节是代码生成接口，不是未经验证的启动脚本：

1. 定位当前可写 ZONE；记录基线，检查管号是否存在。存在时进入修改流程，不能覆盖。
2. 按本机已验证语法创建并命名 PIPE，设置 PSPEC；创建并命名 BRAN，设置相关管材规格、保温等实际字段。
3. 建立头尾与真实 NOZZLE/三通口的连接，核实端点、方向、口径、连接代码和反向引用。
4. 按 PID 创建元件并设置真实 SPREF、ARRIVE/LEAVE、连接和位置；需要的仪表、测温扩大段、旁路不能遗漏。
5. 输出包含所有必需组件的完整单元；最后回读必要端点/规格，确认未创建原点悬空件。

单纯写 HREF/TREF、HPOS/TPOS、HDIR/TDIR、HBORE/TBORE、HCON/TCON 可改端点数据，但不生成几何、不证明反向引用成立，也不能绕过连接兼容性验证。不得把手工填属性当完整连接成功。

## 元件创建与接续

已经确认当前 CE 是正确支路的插入位置、SPREF 可解析且到货连接形式符合要求后，本机会话成功使用的模式：

```text
NEW GASK
SPREF SPEC_GASKET
CONNECT
NEW FLAN
SPREF SPEC_FLANGE
LSTUBE SPEC_LEAVE_TUBE
CONNECT
```

`CONNECT` 会移动/旋转当前组件使其与前件接续；连接不兼容报错或产生默认间隔时，不能当作自动配对成功。不能把“Auto Conn 已勾”作为验证证据。

法兰有设备/密封面端和焊接端。视镜或阀门另一端的配对法兰，可能要 ARRIVE 2、LEAVE 1，而出口法兰为 ARRIVE 1、LEAVE 2；必须用该目录的 P1/P2 验证，不把这个约定推广到其他目录族。

`DIR N/E/S/W/U/D`、`POS E ... N ... U ...`、`BY N/E/W/D ...` 在本机会话用于定位。DIR 后重新看进出口，不能只改朝向而忽略前件对口。POS 一律明确世界/所有者基准；本案例相应所有者与世界基准一致，不保证每个项目如此。

## 异径和直管

- LSTUBE 是该组件后的直管规格，HSTUBE 是支路头部直管规格。设置前看流向及 ARRIVE/LEAVE；异径是 80×50 并不表示它后面的直管永远 DN80。
- 本例 50→80→50：第一异径的离开口为80、LSTUBE 为 DN80；第二异径的离开口为50、LSTUBE 为 DN50。
- 偏心异径大小端中心高差必须回读确认，不能当所有80×50目录的固定偏心量。水平液体排净、顶部排气等要求分别判断平面朝向。
- 两弯头中间距离要扣两端的切线长度。不能在空间不足时让两个弯头重叠假闭合。
- 对焊异径与管焊接；不因口径改变就增加法兰垫片。法兰式异径另按实际目录处理。

## 视镜和软管

读取当前项目的SPCO说明、参数和P-point；PCOM/INST类别本身不能判断视镜、软管或阀门用途。公开版本不携带私有项目目录位号。

本机规格选择代码将 PCOM 显示为 `Piping Component`；其他旧表单可能显示类名。Modify Pipe 的通用设置和管道等级不等于局部插入软管。

软管仅在已确认的连接位置创建，设置长度后CONNECT并回读P1/P2；参数含义按当前目录核实，不能套用其他目录的高度或长度。

```text
REF_HOSE
HEIG VERIFIED_LENGTH
CONNECT
REF_FOLLOWING_GASKET
CONNECT
REF_FOLLOWING_FLANGE
CONNECT
```

改长度后下游不一定自动移动，必须重接续，并确认与固定弯头之间仍有正直管长度。只说“示意”不代表可以穿设备、忽略接口或把普通焊接管统计成软管。用直组件表现软管时注明示意，不承诺真实弯曲半径/采购长度已核实。

## 稳定修改、重排与旁路

通过 Q MEM 得到当前 RefNo，再用 `=数据库号/元素号` 定位。不能将历史 RefNo 复制到未知数据库。优先移动/重排已有组件，不用删除重建改变已连接对象。

本机源代码存在如下重排模式；给当前项目脚本前仍须验证对象属于同一支路、语法适用并检查实际成员顺序：

```text
/PIPE_NAME/BRANCH_NAME
REORDER REF_FIRST BEFORE REF_INSERTION_ANCHOR
REORDER REF_SECOND BEFORE REF_INSERTION_ANCHOR
```

多件按原连接顺序依次插到同一锚点之前，然后逐件 CONNECT 和定位。创建/重排使 FLAN/GASK/PCOM 顺序号改变，后续脚本用固定 RefNo。

三通 P3 对应独立 BRAN，记录 HREF/TREF、P-point、HPOS/TPOS、口径、方向和反向 CREF。主管移动时同步更新三通、旁路端点和弯头；更新坐标不能替代互相连接验证。

本例 BY W/E 的重复执行会累计移位。增量脚本前说明初始状态、位移及只执行一次；用户中断后先看当前状态，不能重复整段。修改入口路线时，保持头部配对件对口，并用重新计算的过渡段连接移动后的组件走廊。

## 视图与输入故障

```text
REM ALL
ADD /VERIFIED_PIPE
ADD /VERIFIED_NEAR_EQUIPMENT
```

只影响显示，不删除数据库。选择地板 PANE 后可 REM ALL、ADD CE 保留选中局部；不要随后 ADD 整个建筑 ZONE 把负担加回。AUTO CE 仅是定位视图，不是连接/碰撞检查。

截图、CE 和命令框输出可能滞后；粘贴末行可能未执行，查询也可能串到前一行。确认回车后的完整返回对象、方向及数值。未成功执行的命令不给“已完成”结论；输入失败不要盲点菜单或把延迟当作软件没有创建。

桥接已在其验证环境测试ALPHA REQUESTS CLEAR和ALPHA COMMANDS CLEAR，每批成功/错误后自动清屏；其他版本仍须核实。不使用猜测的右键菜单或模拟输入。

## 需要项目确认的信息

厂家接口法兰标准/密封面、材料、仪表插入深度、操作站立面，以及碰撞、保温、支撑和坡度等，按当前资料逐项确认。几何连接和目录回读不等于完整工程验收。

## 三个离线行为验收场景

不操作实时 PDMS，检查交付决策而非仅匹配标题：

1. 用户指定 NOZZLE：有 PID、厂家用途和模型属性时先做对应并给快速定位；缺的只补关键字段，不重查全项目，不因同DN选相邻口。
2. 用户要求新管成套代码：从正确 ZONE 到 PIPE/BRAN 初始化、真实端点、全部必需组件和最小回读都覆盖；创建语法未验证时先核实，不能把本次案例包装成已跑通模板。
3. 用户要求入口整体移位并保留旁路：头尾固定；已有元件优先 RefNo 修改；同步旁路与后续软管接续；不能仅移主管、重复 NEW 或沿用旧序号。
