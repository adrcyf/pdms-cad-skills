# 配管走线规划与建模前检查

维护者：adrcyf。适用于新建路线、整段改线、阀组/旁路重排；局部更换同位置元件只复核受影响范围。以下是工作流程，不是替代项目设计规定或厂家安装要求的通用数值标准。

## 1. 先确定工艺和空间约束

- 固定源图/PID版本、流向、真实起终接口及其连接面世界坐标、向外轴、DN/实际外径、管道等级和保温条件。PID确定拓扑和工艺要求；图中符号的左右上下不直接变成三维走向，特殊坡度/液封/排净注记仍须落实。
- 区分普通液体、重力排液、泵吸入、蒸汽、冷凝水及其他特殊服务。按本管线资料确定坡向、允许高低点、仪表直管段、振动/热位移等约束；不能给所有介质套同一坡度、异径朝向或最少弯头规则。
- 从当前模型/资料读取墙梁柱、楼板、设备、现有管线/管架和可用开孔；世界变换后形成障碍范围。未知范围标出，不能用屏幕空白证明没有障碍。
- 同时建立操作检修禁入区：人员通道、平台站立面、门扇、人孔/盖板开启、换热器抽芯、泵/电机抽出、设备搬出和已知吊装路径。禁入区即使没有实体也占空间，不能靠几何不碰撞放行。
- 开放公用工程端仅在用户授权范围确定模型边界，记录暂定来源，不移动真实设备接口来凑路线。未经授权不添加/删掉PID阀门或改工艺拓扑。

## 2. 先确定走廊和标高

每条路线先写清从设备哪一侧进入哪个走廊，主水平段中心标高或坡度起止标高，允许升降的位置，以及离开走廊接终口的方法。

优先研究已核实可用的管架、结构附近及已有同类布管走廊，维持有意义的并排方向和标高层次；不能为齐平强行违反排净、热位移、支撑或端点方向。沿结构走不等于已获结构承载许可，墙体也不自动成为合法支撑点。穿墙/板须有依据的开孔/套管和相关要求，不能穿实体或临时猜开孔。

标高统一为世界中心线标高，并记录控制位置的管底/保温底、法兰及阀组外包络；操作高度从真实站立面计算。没有依据时不要直接指定万能操作高度或净空值。对重力流/排液等受约束路线优先落实坡向和标高，再处理易调整段。多管同时布置时说明排序依据，通常先安排空间/坡度/端点约束更严的管线；不能把“大管永远优先”等经验当硬性通则。

## 3. 先排阀组、仪表和拆卸组件

- 先确定操作侧、操作站立面及接近路径，再摆阀组和仪表。记录阀体/执行机构方向、手柄或手轮全行程、读表/视镜视线、检修拆出方向和拆卸连接位置。手轮朝向不能只凭外观统一设置，遵从厂家允许方向及工艺要求。
- 按目录真实P-point、安装长度、法兰垫片和弯头切线尺寸累计阀组总长，预留有依据的仪表直管段及安装/拆卸空间。先把关键组件放进可用空间，再连接上下游；禁止管子画完后将组件硬塞到余隙。
- 检查阀组能否操作、隔离后能否拆出、紧固工具能否进入，旁路和相邻管线是否阻挡；不能仅凭阀中心离地高度合适判可达。
- 核对可行支撑位置、重件承托及热位移方向。不得把泵嘴/设备嘴当悬臂管架，或用外观贴合代替载荷校核。未做应力、支撑或载荷核验时明确该范围待确认，不宣称完整工程验收。

## 4. 离线形成并比较候选路线

在正式创建或移动路线前，至少比较两个有实际差异的可行候选，例如设备另一侧走廊、不同合法标高层或阀组位置。只有一个可行方案时记录其余候选被排除的约束；不制造绕路方案凑数。已有指定路线只评估合法替代，不擅自改动用户指定边界。

先判硬约束，再在通过的方案中比较质量：

| 检查顺序 | 内容 | 处理方式 |
|---|---|---|
| 硬约束 | 工艺拓扑/固定端点与方向、规定坡向、实体/禁入区、安装及操作检修所需空间 | 冲突即排除，不能靠短距离或少弯头分数抵消 |
| 硬约束中的未知 | 影响可行性的关键尺寸、障碍、站立面或所需净距无依据 | 标记待核；不报通过，不创建依赖该假设的正式段 |
| 软目标 | 总长、弯头数、无必要升降、共享走廊、支撑可行性、安装及日后检修便利性 | 比较实际差异，给选用理由，不只选最短 |

基本走线优先清晰的正交段，必要斜段须有工艺/空间依据。不要为了绕过尚未核实的障碍连续增加弯头；先重新核实走廊和组件位置。对高温等服务，满足柔性/热位移要求所需转弯不能当多余弯头删除。

## 5. 按实际外包络检查

几何、距离、坐标变换和候选段计算交给Python或可靠几何工具，不用语言估算冒充测量。直管检查半径取`实际外径/2 + 保温厚度`；平行直管所需中心距至少为两侧外包半径之和再加本项目要求净距。DN不等于外径，法兰、阀体、执行机构和手柄运动范围须单独建包络，不能套直管半径。

按真实目录切线长扣除弯头占用，检查剩余直管满足安装/焊接及厂家直管段要求，禁止零长、负长或弯头互相重叠。不能用研究算法中的假定弯曲半径或最小段长代替当前目录实测。

保守包围盒可作初筛；命中须进一步检查，不把保守盒重叠直接当实体穿透。未检查的细节、漏读对象或未知保温条件写入覆盖范围，不能把局部抽查表述成全线无碰撞。若所需净距缺来源，列待确认值，不能随意指定一个数然后称合格。

## 6. 规划表完成后再建模

规划可用一份紧凑表格或等价结构化数据，无需另写冗长报告；已有执行授权时由助手完成比较和检查后继续，不增加逐段用户审批。交给执行子代理时传递这些结果，不让其重新猜走向。

| 规划内容 | 必填信息 |
|---|---|
| 边界与依据 | 图纸/PID版本；源、终接口路径/RefNo；世界连接面坐标和方向；固定/暂定字段 |
| 工艺约束 | 介质/服务类别、流向、坡向/标高、等级/保温及所需组件顺序 |
| 走廊与标高 | 主走廊范围、世界中心线标高/坡度端点、升降位置、支撑依据 |
| 阀组 | 操作侧/站立面、组件次序、总安装长、方向、操作及拆卸包络 |
| 候选比较 | 每方案主要路径、长度/弯头/升降、空间检查结论、选用或排除理由 |
| 选定路线 | 完整转折点或等价段表、组件位置、相关检查结果及仍待确认范围 |

没有完成与拟建段相关的走廊、标高、阀组和空间检查时，只做只读测量和离线规划，不发送正式建管、移管或摆件命令。关键未知只阻断依赖它的段，其余有完整依据的独立单元可继续；不得把受阻单元拆成无验收价值的小段来绕过检查。

## 7. 修改与验收

端点、组件安装长度、阀组位置、走廊、障碍、站立面或保温变化时，重算受影响候选和净距后再改；禁止边接边绕、边错边加弯头。一个PDMS会话只由一个执行代理发送实时命令。

建模后对照计划回读连接面/P-point、朝向、转折标高和组件顺序，检查实体/保温/运动包络与操作检修空间。规划检查和模型回读分别给结果；任何一项只做局部或尚未验证就明确范围。最终说明选用路线理由、偏离计划的地方、待核项及保存状态，命令成功不等于设计通过。

## 来源和采用边界

以下为流程与方法参考，不是本项目强制数值规范；具体数值优先采用有效项目规定、批准图纸和对应厂家资料。

- [piping-design-skill](https://github.com/boudjadayoucef-sketch/piping-design-skill/blob/main/SKILL.md)：结构化管段、Python几何和连通性检查；不能凭其主说明认定已具备PDMS工程布管能力。
- [Pipe Routing & Installability Tool](https://github.com/LaurensOTU/Pipe_routing_tool_software)：先定义障碍/走廊，再比较带弯头、安装性等目标的路线；船舶研究原型，不直接移植船级规则或宣传其成熟度。
- [From Multi-Agent Pathfinding to 3D Pipe Routing](https://harabor.net/data/papers/bddhkw-fmapft3dpr-socs20.pdf)：物理/逻辑障碍、管径净距、支撑/弯头成本和多管排序；文中简化和数值不是通用设计标准。
- [工程社区：Equipment spacing](https://www.reddit.com/r/ChemicalEngineering/comments/1k0x67n/equipment_spacing/)：操作、检修和搬出空间经验；社区建议不直接作为强制净距依据。
- [工程社区：PID与实际走向](https://www.reddit.com/r/ChemicalEngineering/comments/1n968cn/how_to_draw_this_on_a_pid/)：拓扑与空间布置的区别，特殊工艺注记仍需落实。
- [Spirax Sarco：仪表安装](https://www.spiraxsarco.com/learn-about-steam/flowmetering/installation?sc_lang=en-GB)：按对应型号核对直管段和安装要求。
- [Spirax Sarco：蒸汽干管排水](https://www.spiraxsarco.com/learn-about-steam/steam-distribution/steam-mains-and-drainage)、[膨胀与支撑](https://www.spiraxsarco.com/learn-about-steam/steam-distribution/pipe-expansion-and-support)：蒸汽服务的排水、柔性和支撑；不得把蒸汽专用规则推广到所有介质。
