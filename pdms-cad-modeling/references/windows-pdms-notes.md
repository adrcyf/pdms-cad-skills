# 本机PDMS操作与验证经验

以下是2026-10-26在本机PDMS 12.1 SP4的观察，不是跨版本保证。只在需要对应操作时使用；先核对当前环境。Windows界面操作遵循可用的computer-use技能，不另写底层UI自动化。遇截图问题先读本机已有computer-use-repair.md，不将旧补丁用于未知版本。

## 宏输入与恢复

- 本机含中文的Design宏曾因UTF-8输入在中文行前停止，CP936/GBK、CRLF输入成功；原生DATAL输出则为UTF-8 BOM。先用最小、可回读的操作确认编码，不能把“有宏文件”当执行成功。
- 命令框set_value曾超时但实际已写入，截图与辅助功能文本也可能延迟。重新观察并确认命令内容/焦点，再执行；先查日志结束标记、元素是否已创建，避免重复运行NEW造成重名或重复实体。
- 宏分阶段写日志和完成标记。失败后检查停在哪一行、哪些操作已生效，只接续剩余部分。日志未关闭时先结束已知打开的日志；没有日志时不要盲加关闭命令。表达式保留清晰空格，尤其减号，避免解析为标识符。

## 对象、目录与曲面

- 本机基本体不支持DESC，不能把EQUI/SUBE/NOZZLE属性批量套在基本体上。NOZZLE也不支持基本体的LEVEL属性；不要用失败的Q/设置当成已隐藏。
- 先回读SPCO的Answer、CATREF、所属SELE说明，以及SCOM的参数、P-point和GMSE表达式。参数序号含义随目录族变化。
- 在本机已核查的WN族中，法兰高度H包含颈，HEIG是P1到P2总长，额外接管长为HEIG−H；该关系只可用于实际读取证明相同的目录族，不能推广到所有接口。
- 原生封头曾在给定外径和高度相同的情况下仍与CAD圆弧不同。以实际射线/截面验证为准；若用圆台分段替代，排除旧隐藏封头参与命中判断，检验分段连续性及最大近似误差。

## 显示与导出

- 原生DATAL可能省略基本体LEVEL，但将NOZZLE目录引用写在尾部`OLD NOZZLE ... / CATR SPCOMPONENT ...`，不能只搜索SPREF或CATREF便断言引用缺失。
- 对需要保留的隐藏基本体，原生Q LEVEL确认后，在重建宏对应创建处恢复LEVEL。不要把显示列表状态误认为数据库显示属性。
- 如果替代NOZZLE的标准外形与CAD外观冲突，可在用户允许的范围内保留接口数据，单独建立CAD外观，并以明确的成员显示列表排除替代外形。提供恢复该显示列表的宏；重新ADD整个EQUI会重新包含这些标准外形。此做法不等于修改了CATR，也不能据此声称真实连接制式或目录碰撞包络已一致。
- 保存数据库、导出数据、恢复显示是不同的验证对象。分别检查SAVEWORK完成、导出内容和当前视图；未在第二数据库试导入时不要宣称重建已实测通过。
