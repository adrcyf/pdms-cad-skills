# 核对表与对照报告

用于交付逐口核对表、报告及整理交付文件。数据来源保持可追溯，项目中的实际编制人、设计确认者与 skill 原作者分别记录。

## 统一逐口核对表

每个原图接口编号一行，至少包含以下字段；同一行存在不同依据时分字段写明，不用整行“已核实”掩盖局部暂定。

| 字段组 | 必填内容 |
| --- | --- |
| 标识 | 接口编号、中文用途、PDMS 路径、所属组件 |
| 原设计 | DN、压力等级、原连接形式；原图未给值写“原图未标” |
| 定位 | 连接面中心局部 E/N/U、向外轴矢量、方位角及倾角、角度零点与正方向、单位和基准 |
| 几何 | 接管外径、法兰/卡盘外径、定位半径、接管长度及其定义 |
| 目录 | 实际 CATR、所选规格和压力、目录外径；替代时保留原连接形式和尺寸差异 |
| 依据 | 各字段对应的图名/视图、尺寸或图元标识、测量/计算方法；标注图纸实测、投影解释、近似长度、目录替代或暂定定位 |
| 执行检查 | PDMS 回读值、偏差和单位、目录可解析情况、接合检查结果及检查日期 |
| 使用者确认 | **需核对内容、确认结果**；有确认时记录确认人、日期和证据 |

“确认结果”默认“待确认”，只有可追溯的使用者或设计确认才能更改。已收到的具体授权可记“已授权暂定：字段/范围”，该字段仍保留暂定状态；回读一致只表示模型按选定数值执行。无需确认的确定字段注明来源，避免让使用者重复确认全部实测尺寸。

典型待核对内容包括：缺失标高或方位、两个视图无法兼容的关系、推断轴向、近似伸出长度、目录替代的连接面/压力/外径差异。非接口组件的暂定项（如执行机构方位）放在同一交付表的组件备注区，或报告的待核对清单，不能遗漏。

## CAD/PDMS 对照报告

按交付要求生成可编辑 Word，需固定版式时同时导出 PDF。标题、版本、日期、实际编制人及单位写在首页；编制人来自用户或项目授权，不能因采用本 skill 自动填“adrcyf”。署名不表示第三方机构已审定。

建议结构：

1. 模型对象、源 CAD、单位、局部坐标与展示位置；完成范围和当前适用限制。
2. 整体、顶部俯视、关键接合、出料组件的 CAD/PDMS 对照图及简短核查结论。
3. 接口规格和可见外形差异，特别是 DN、定位半径、接管外径和法兰外径的区别；说明替代目录与单独外形表达的关系。
4. 实测、投影解释、近似长度、替代目录、暂定定位汇总，列出具体接口/字段和后续需确认内容。
5. 验证方法、最终交付文件及使用/显示恢复方法。

使用最新模型的真实截图；CAD 与 PDMS 尽量采用相同视向、角度基准和可比较的设备区域。为每组图片标注视向、接口编号、来源和模型阶段；不同缩放时注明，不能用图上像素直接比较尺寸。局部被遮挡时补另一视向，缺图需补拍；历史截图不得当成当前修复结果，未修复的差异直接披露。

图片嵌入文档，并在图注给出读者需要的尺寸或判断依据。导出后逐页检查中文、图像清晰度、编号、署名、分页和表格；核对总接口数与最新模型一致。将关键证据摘要写入表格/报告，不让最终交付依赖待删过程文件。

## 交付整理与来源

成品验证后，依据用户清理授权及本机清理约定，核对绝对路径、文件清单和属性，再清理本任务过程文件。保留最终模型、必要恢复方法、统一核对表、报告及原始资料；未知文件留存。
